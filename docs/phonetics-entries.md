# Fichas de letras y ejemplos regionales
La vista FON01 añade un selector de 27 letras. Cada ficha separa nombre recomendado, AFI del nombre, fonema, realización amplia, articulación y al menos dos palabras. La tabla completa permanece disponible dentro de un desplegable.
Q reproduce cu para el nombre y queso para el sonido en contexto. H conserva el audio de hache y de las palabras, pero no ofrece un supuesto sonido propio. Se precisa que el silencio corresponde al uso general estándar, con aspiración dialectal y ciertos préstamos como ampliación. V se presenta con /b/ y realizaciones bilabiales [b] y [β̞], sin imponer [v].
Los modelos de referencia de la ficha se sincronizan con la selección regional de audio. La síntesis sigue dependiendo de las voces del dispositivo y no se afirma que esté revisada contra cada AFI. Las transcripciones amplias son modelos de referencia y no una representación universal de una región. Cuando no hay una diferencia regional relevante se conservan transcripciones iguales.
El banco amplía cerca, zapato, casa/caza, me llamo, lluvia, calle, yo y mayo. [ʎ] se clasifica como no yeísta; el yeísmo no rehilado, el zheísmo y el sheísmo aparecen separados. El seseo andaluz y el mexicano comparten la ausencia de oposición, no todos sus detalles fonéticos.
Las nuevas palabras se registran en el sistema de audio existente. Las fichas son bilingües ES/NL, sus controles tienen nombres accesibles y dimensiones táctiles mínimas. La exploración no modifica el progreso ni crea evidencias de pronunciación.
El PDF incorpora las distinciones y referencias nuevas, con ejemplos por modelo; las realizaciones idénticas se condensan. La tabla antigua de abecedario no se duplica en la impresión. Se conserva el flujo de favoritos y colecciones.
Se añaden siete pruebas para contenidos, reproducción separada, sincronización, clasificación dialectal, neerlandés, PDF y edición autónoma. La suite completa supera 82 pruebas funcionales. Las voces se simulan en las pruebas; no constituyen una validación auditiva. Siguen pendientes la revisión visual y la auditiva en dispositivos reales y la incorporación de grabaciones o voces regionales verificadas.
