# Segundo lote: contexto y evidencia de recuperación

Se conservan los 80 ID de tarjetas. Cada tarjeta original tiene ahora senseId y contextId estables. Se revisan alternativas neerlandesas para levantarse, entender, repetir, el billete y la retroalimentación. Son alternativas para el sentido de los ejemplos originales, no una aceptación universal de traducciones. Las notas contrastivas aparecen después de responder.

Los eventos answer nuevos incluyen schema 2, modalidad, número de intento, sesión y contexto. Se sigue usando el kind review existente; no hay migración destructiva. Los clientes anteriores conservan los campos y los eventos de exposición al sincronizar. Los eventos históricos no se reescriben.

Se registran soluciones mostradas en tarjetas, corrección, final de test y opciones de emparejamiento. La recuperación diferida considera las respuestas y exposiciones registradas de ambas direcciones. El indicador a tres días exige producción correcta sin ayuda en el primer intento de un evento nuevo con schema 2. El estudio externo y la consulta libre no se observan, por lo que el indicador no certifica retención ni dominio.

Una sesión reanudada conserva los intentos y ayudas de la pregunta actual. Al avanzar se reinician esas marcas para la siguiente pregunta. Las sesiones antiguas sin datos suficientes se retoman de forma conservadora como asistidas. La repetición de un envío ya resuelto no crea otra respuesta.

El panel separa reconocimiento con opciones, producción independiente, producción asistida y registros antiguos de modalidad desconocida. Las direcciones ES/NL no se presentan como si fueran por sí solas modalidades receptivas o productivas. El cálculo del repaso agrupa eventos por tarjeta antes de evaluarlos para evitar búsquedas completas por cada elemento.

Pendiente de siguientes lotes: ampliar sentidos y combinaciones al resto del vocabulario con revisión lingüística, contrastes manipulables adicionales, propuestas VO/MBO y medición de transferencia. No se marca automáticamente como evaluada una frase abierta ni se infiere capacidad docente de estos resultados.
