# Audio de la sección de fonética
La sección incorpora botones independientes para nombres de las 27 letras, dígrafos y ejemplos españoles registrados, tanto en las tablas como en un banco por módulo. Las combinaciones velares se escuchan dentro de una palabra identificada; no se intenta sintetizar símbolos AFI como texto corriente. La secuencia gu de gusano y el dígrafo gu de guerra usan ejemplos diferentes.
El laboratorio Prueba tu propia frase acepta hasta 500 caracteres de texto plano, conserva el texto durante la navegación de esta sesión, permite seleccionar una variante y velocidad y ofrece reproducción y detención. El texto no se guarda en el perfil ni modifica evidencias. La síntesis del sistema puede emplear servicios de voz del dispositivo.
La reproducción usa SpeechSynthesis y las voces españolas que el dispositivo expone. Es-ES, es-MX y es-AR se buscan por locale; es-UY es también una voz candidata para la opción rioplatense. No se sustituye una opción regional ausente por una voz de otro país. La opción separada Español disponible, sin garantía dialectal permite usar conscientemente una voz española alternativa.
Las voces se identifican al reproducirlas y se etiquetan como sintéticas. El código regional no garantiza distinción, seseo, sheísmo o zheísmo en cada emisión. No se han agregado grabaciones humanas ni se afirma disponer de tres acentos nativos verificados. El servicio de producción no tiene credenciales de un proveedor de síntesis configuradas.
El manifiesto recordings admite futuras muestras con tipo human o synthetic, URL, créditos y reviewStatus verified. Las muestras pendientes no se presentan como grabaciones válidas. Para garantizar los tres modelos en cualquier dispositivo es necesario incorporar audios revisados o configurar un servicio estable con voces revisadas. Esa parte no queda sustituida por la síntesis del navegador.
El reproductor detiene la emisión anterior al cambiar de ejemplo, variante o ruta. Maneja descubrimiento tardío de voces y errores. Los controles tienen nombres accesibles, área mínima de 44 píxeles y estados de disponibilidad. La impresión conserva el contenido estático y omite reproductores.
Las pruebas funcionales usan voces simuladas: verifican el enrutamiento y los estados, no la realización acústica. La revisión auditiva en dispositivos reales y la revisión visual siguen pendientes.
